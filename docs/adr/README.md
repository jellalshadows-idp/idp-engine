# Architecture Decision Records

An ADR records one decision that shapes this platform: the context that forced it, what was decided, the consequences, and the alternatives that were rejected. The [design spec](../superpowers/specs/2026-10-08-idp-on-actions-design.md) describes the system; the ADRs explain why it looks that way. A new ADR is required for any decision that changes a spec-level contract.
